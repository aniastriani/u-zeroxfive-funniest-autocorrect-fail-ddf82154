## What it does

`main.py` (pure Python standard library, no dependencies) writes one line
— under 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is a
text message in which autocorrect swaps "marry" for "bury" in a romantic
message, and the sender catches the slip mid-text and panics:

> Babe, I love you so much, I can't wait to marry you — I mean MARRY,
> autocorrect, not bury. Please don't leave me.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Deterministic: the same line on every run. Exits 0 on success.
